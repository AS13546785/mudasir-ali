# Mudasar Ali — Off-Page SEO & Guest Posting Expert

A modern, high-performance, and responsive personal portfolio website showcasing expertise in Off-Page SEO, high-authority link building, and guest posting services.

---

## 🌟 Key Features

- **Hero Section:** Dynamic live-glow circular avatar frame, stylish script typography (`Birthstone`), and ambient particle background.
- **About & Experience:** Highlighting industry experience, client success metrics, and counter statistics.
- **Services Showcase:**
  - High Authority Guest Posting (DA/DR 50+)
  - Contextual Backlink Building
  - Competitor Backlink Audits & Outreach
  - Niche-Relevant Anchor Strategy
- **Payment & Client Proofs:** Interactive carousel featuring verified client work and payment proofs with lightbox view.
- **Client Reviews & Testimonials:** Smooth swipeable review cards with uniform card layouts and verified feedback.
- **Interactive Contact:**
  - Direct WhatsApp quick-connect integration
  - Interactive contact form with live responsive popup feedback
- **Smooth Navigation:** Back-to-top button, animated transitions, custom theme scrollbar, and full mobile responsiveness.

---

## 🛠️ Built With

- **HTML5 & Modern CSS3** — Flexbox, CSS Grid, Custom Variables, Fluid Typography (`clamp`)
- **JavaScript (ES6+)** — Drag-scroll carousel, interactive lightbox, modal popups, performance optimizations
- **Particles.js** — Ambient floating particle background effect
- **AOS (Animate On Scroll)** — Smooth scroll reveal animations
- **Font Awesome 6** — Icons
- **Google Fonts** — Birthstone, Inter, Poppins
